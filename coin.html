coin. — daily finance tracker

A minimal daily finance tracker for iOS and Android — no spreadsheets, no syncing, no subscriptions. Log income and expenses in seconds and let the app tell you where you stand. Built solo in Flutter, single codebase, fully offline. Part of Orbit, a suite of three minimal daily-habit apps sharing one design language.

Flutter & Dart · Solo developer · Aug 2025 – present

What it does

  • Log income and expenses with a label and amount; see a big animated net-total for the day.
  • Net-per-day status is color-coded — green for net-positive, yellow for a small loss, red beyond a set threshold — reflected in the net figure, progress bars, and calendar dots.
  • A 5-step goal-setting quiz on first launch sets daily/monthly/yearly spend and savings targets, tracked with live progress bars.
  • Calendar view of every day, daily notes, swipe-to-delete with confirmation, and haptic feedback on entry.
  • Fully offline — everything stored on-device via shared_preferences.

Engineering highlights

  • Global theme toggle done without an external state package. A ValueListenableBuilder<bool> drives light/dark mode app-wide, with a custom theming layer built to work around Flutter's widget-canonicalization behavior — by default, identical widget subtrees can get reused across a rebuild in a way that silently skips the rebuild a theme change needs, so the toggle has to force it explicitly.
  • Diagnosed and fixed an animation bug in the net-total figure. The large animated number was supposed to count up from $0 once on load, but kept re-animating from $0 on every data update instead of snapping straight to the new value. The cause: TweenAnimationBuilder only honors its begin value on a widget's true first build — later rebuilds animate from whatever is currently showing. The fix was keying the widget on a dataReady flag, so the moment loading finishes, Flutter treats it as a fresh first build and the number snaps to the real value; later adds/deletes still animate normally through the update path.
  • Net-color rule is a single threshold constant (green > $0, yellow between $0 and –$30, red beyond –$30) shared by the net figure, progress bars, and calendar — one source of truth instead of duplicated logic.
  • The app icon is the in-app graphic, exactly. coin.'s launcher icon is generated by rasterizing the same hand-rolled CustomPainter graphic used on the intro screen — via a Flutter widget test repurposed as a one-off build script — so the icon and the in-app art never drift out of sync.

Testing & verification

Solo developer, no dedicated QA — verified manually during development, before each merge:

  • Smoke-tested every feature on iOS Simulator and Android Emulator before merging, across both light and dark themes.
  • Regression-tested the net-total animation bug against its original repro steps after fixing it, alongside the normal add/delete/toggle paths, to confirm nothing else broke.
  • Ran flutter analyze (flutter_lints) as a static-analysis gate. test/ currently holds Flutter's default scaffolded test plus the icon-export script — not a functional test suite yet, which is the near-term gap.
